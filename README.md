# The Product Engineer

> From Code to Scaled Architecture

A structured, open-source engineering handbook covering core client-side foundations, modern JavaScript runtimes, declarative component systems, backend architectures, distributed caching, and scalable system design.

---

## Curriculum Overview

### 1. Frontend Architecture
- **HTML5 & Semantic Web**: Document hierarchy, semantic landmarks, accessible forms, audio/video media, technical SEO, and WCAG accessibility standards.
- **Modern CSS3 & Design Systems**: Box model, specificity and cascade algorithms, Flexbox, 2D CSS Grid, OKLCH wide-gamut color spaces, fluid clamp calculations, and animations.
- **JavaScript (ES6+)**: V8 engine internals, memory heap vs call stack, Event Loop concurrency, closures, promises, and asynchronous execution.
- **React.js Foundations**: Vite setup, JSX syntax rules, components, props, useState, controlled forms with real-time validation, useEffect, native API fetching, and client-side routing with React Router DOM.
- **Next.js Full-Stack Architecture**: React Server Components (RSC), App Router file-system routing, Server Actions, client hydration, dynamic rendering, SEO metadata, and scaled production workflows.

### 2. Backend & Scaled Architecture (Upcoming)
- **Node.js**: Asynchronous event loop phases, streams, buffers, and child processes.
- **Express.js**: REST API patterns, middleware pipelines, Zod schema validation, and structured error handling.
- **Databases & Caching**: PostgreSQL relational modeling, indexing strategies, and Redis Cache-Aside patterns.
- **System Design & DevOps**: Docker containerization, asynchronous background job queues, and scalable infrastructure.

## Getting Started

### Prerequisites

- Node.js 18.0 or higher
- npm 9.0 or higher

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/harshitclub/the-product-engineer.git
cd the-product-engineer
npm install
```

### Local Development

Start the VitePress development server:

```bash
npm run docs:dev
```

The documentation will be available locally at `http://localhost:5173`.

### Production Build

Generate the static production build:

```bash
npm run docs:build
```

Preview the production build locally:

```bash
npm run docs:preview
```
